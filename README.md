# NIVORA Trade — V7

Dashboard NIVORA Trading in modalità **paper/backtest**.

- Rischio massimo: 1% per posizione
- Una sola posizione alla volta
- Nessuna martingala
- Nessuna leva
- Nessun ordine reale viene inviato

## Avvio locale
```bash
npm install
npm start
```

Poi apri http://localhost:3000

## Render
Il progetto include `Dockerfile` e `render.yaml` per la pubblicazione come Web Service.
